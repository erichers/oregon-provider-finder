About the data

This directory lists individual clinicians with an Oregon practice address in the federal NPI registry. It includes physicians, nurse practitioners, physician assistants, psychologists, counselors, social workers, and marriage and family therapists.

The registry does not record insurance, whether someone is taking new patients, languages, or conditions treated. Specialty names come from the NUCC taxonomy, which is a billing classification, not a full description of a practice.

Locations are ZIP code centers from the Census Bureau, then a city center when the ZIP is missing. They are not street geocodes. The map uses the same centers.

Plain-words search sends your sentence to a chain of free language models. The server checks the answer against the real groups, credentials, and places, and drops anything the registry cannot filter. If the models fail, a small set of rules does the same job. The page tells you which parts it understood.

The site does not use tracking cookies, and it does not store the text you type.
